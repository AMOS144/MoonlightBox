# 前端交互状态修复

本次只修复前端交互与状态衔接，不改变 Agent、任务调度或真实数据。

## 修复范围

1. 人物纠正提交期间暂时锁定输入，避免用户继续编辑后被成功回执清空；请求失败保留原草稿并恢复编辑。
2. 纠正的发送、取消、批准、范围确认等写操作共用 busy 状态；需要重新读取状态的操作等待刷新完成后再解锁。
3. 会话缓存对 GET、SSE、操作回执统一比较 session_revision，同版本比较 updated_at；旧响应不能覆盖新状态。
4. 节点栏目重试记录 Job ID，持续查询后台状态，刷新或返回页面可恢复；完成后自动读取新审核草稿。后台失败和读取失败保留恢复入口，不自动无限重试。新审核版本不携带旧选择。
5. 创建项目期间离开页面会停止前端等待；即使网络层仍交付迟到响应，也不再跳转。此行为不代表撤销后端已经创建的项目。
6. 导入确认按项目和预览 ID 保存，并可从后端已导入列表恢复。更换目录不会沿用上一批确认。
7. 分支准备页面分离查询错误与恢复操作错误；重读时清理旧操作错误，已就绪时不再展示过期失败提示。
