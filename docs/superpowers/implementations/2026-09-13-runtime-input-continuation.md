# 移除普通新输入导致整轮作废的策略

普通聊天消息入库不再递增分支 runtime_input_revision。Director、DayPlan、PersonaActor、
生活事件协商和最终提交都不会仅因为新消息到达而判定当前执行过期。
新增消息仍独立入队并保留 pending 状态，本轮只处理自身决定引用的消息与领取的事件。

数据库列名暂保留，以免此次改动迁移历史检查点；其含义收窄为分支执行代际，
只在显式背景切换、时钟控制等场景变化。对应的取消、租约和执行条件检查仍保留。
PersonWorld 用户纠正版本检查不属于普通聊天作废策略，不删除它。

新增并发输入冒烟覆盖 Director 推理期间与 PersonaActor 表达期间入队新消息：
当前回复提交成功、无额外 Director 重跑、新消息和事件继续待处理。

本次仅移除旧失效策略。3 秒空闲调度节拍、模型调用前批量续接所有未读输入，
以及连续执行的输入游标尚未实现；不能将当前逐事件唤醒宣称为完整时间片调度。
